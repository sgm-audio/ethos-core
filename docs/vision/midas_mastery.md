  Format: One-page tactical reference. Print this and tape it to the dogbox.

  MIDAS PRO 2: TACTICAL COMMAND SHEET


  CRITICAL WARNINGS (The "Don't Get Fired" Zone)
   * SOLO IN PLACE (The Red Flap): DO NOT LIFT. If active, soloing a channel mutes the entire PA. Use standard PFL/AFL
     only.
   * HEADPHONE PATCHING: The desk defaults to silence. You must patch Monitor A (L/R) to Headphones (L/R) in the
     Patching > I/O menu before putting headphones on.
   * MONITOR FADER TRAP: Do not press "Assign Headphones to Fader" if the fader is at 0dB. It jumps to unity
     immediately. Ear damage risk.


  NAVIGATION LOGIC
   * POP GROUPS (Population Groups): These are your "Views." Pressing a POP group "spills" its assigned channels to the
     Input Faders (Left Side). Preferred over VCAs for navigation.
   * EXTEND BUTTON: Maps Input Faders onto the Output/VCA section (Right Side). Gives you 16 faders of inputs instead of
     8.
   * AREA B: If you assign a Pop Group to "Area B," it locks those channels to the Right Side (Output Faders), keeping
     your Left Side free for mixing.


  THE "HIDDEN" BUTTONS
   * HOME: Press Console Overview once.
   * METERS: Press Console Overview twice.
   * ALT BUTTON: Changes functionality based on screen context (e.g., switches Aux Send from On/Off to Pre/Post).
   * ENTER BUTTON: Used to "dive in" to a selected parameter on the screen (e.g., changing Aux routing).

  2. The "7 Secrets" (Content for the PDF)


  Title: The 7 Esoteric Secrets of the Midas Pro 2
  Subtitle: Features hidden so deep they might as well be classified.


  SECRET 1: The "Auto-Mixer" Insert Hack
  The Auto-Mixer isn't a simple button; it's an FX rack unit.
   1. Go to Effects Rack > Change Device > Select Midas Automixer.
   2. Go to Patching.
   3. Route Channel Insert Sends -> Auto Mixer Inputs.
   4. Route Auto Mixer Outputs -> Auxiliary Inputs (Return path).
   5. Result: Perfect for panel discussions.


  SECRET 2: The De-Esser Loop
  Similar to the Auto-Mixer, the De-Esser requires manual insert patching.
   1. Load De-Esser into FX Rack.
   2. Patch Channel Insert Send -> De-Esser Input.
   3. Patch De-Esser Output -> Channel Insert Return.
   4. Activate: Press the INS (Insert) button on the channel strip.


  SECRET 3: The "Talkback" Matrix
  The Talkback section is a router, not just a mic.
   * Internal Talk: Routes the Talk Mic to internal busses (Aux/Matrix/Groups).
   * Pink Noise Generator: Press Oscillator + Talk to send pink noise to selected busses for system tuning.
   * External Talk: Allows you to route the Talk Mic to a physical output (for a "Voice of God" mic or separate shout
     speaker).


  SECRET 4: The "Direct Out" Clone
  Need a recording feed or a split without affecting the mix?
   1. Go to Patching.
   2. Select Direct Outs (Source) -> Physical Output (Destination).
   3. On the Channel Strip: Unmute the Direct Out button and adjust the level knob.


  SECRET 5: The Headphone Fix (The "Worst Feature")
  The most common panic moment on a Pro 2.
   * The Problem: Default state = No audio in headphones.
   * The Fix: Go to Patching > Monitor tab. Patch Monitor A Left/Right to Headphones Left/Right. Save this in your start
     scene.


  SECRET 6: The "Sidechain" Ducking Circuit
  Perfect for DJs or Voiceovers over music.
   1. Go to Patching.
   2. Select Input Channel (Source, e.g., Host Mic) -> Sidechain Input (Destination, e.g., DJ Channel).
   3. On the DJ Channel Compressor: Turn on Sidechain.
   4. Result: Music drops automatically when the host speaks.


  SECRET 7: Recall Safes (The "Job Saver")
  Prevent your automation from ruining the show.
   * Go to Automation > Recall Safes.
   * "Safe" the MC Mic, BGM, and Master Fader.
   * Now, when you hit "Next Scene" for the band, the MC mic stays live and doesn't reset to -inf.
